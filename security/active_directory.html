Directory Security Issues

Problems identified during the MLHMS legacy review

Disabled AD account remains active in MLHMS When an employee is terminated, Active Directory is disabled but some legacy applications retain locally stored accounts.
Multiple identity stores Users can have separate credentials for MLHMS, laboratory, billing and other departmental systems.
Excessive directory privileges Some IT groups grant broad administrative rights that are not restricted according to least privilege.
Unknown service-account ownership Several service accounts lack documented owners, expiry dates or regular review schedules.
Inconsistent synchronization Applications maintain different states for the same employee account.
