Known Legacy Design Issues

Client-side security assessment The evaluator provides useful feedback but is not integrated with a central enterprise identity policy. Different applications may enforce different password requirements.
Password expiry does not equal strong authentication The legacy environment emphasizes periodic password changes but does not provide MFA or adaptive authentication.
Local account stores Some MLHMS modules maintain local credentials independently of Active Directory.
Inconsistent policy enforcement Laboratory, billing and administrative applications may apply different password rules.
